# Local LLM Hub (Obsidian plugin)

## Version control / deployment
- Fork of takeshy's plugin; `origin` = https://github.com/OlivierLmr/obsidian-local-llm-hub.
- Commit on `main` unless explicitly asked otherwise (other branches are PR branches to
  upstream). Commits are GPG-signed (`commit.gpgsign = true`).
- Push after each commit without asking.
- Message style: conventional prefix, lowercase (`fix: …`).
